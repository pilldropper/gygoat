# GYGOAT

A desktop video downloader built with Tauri, React, TypeScript, and Rust.

## Goals

- Clean desktop experience for yt-dlp
- Easy format selection
- Download queue management
- Cross-platform architecture

## Tech Stack

- Tauri
- React
- TypeScript
- Rust
- yt-dlp
- FFmpeg

## Current Status

Early development.
